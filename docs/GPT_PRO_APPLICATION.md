# GPT Pro Support Application Draft

Lingxiao AI Manager is an open-source, local-first desktop utility for
developers who use AI coding IDEs heavily. It helps users organize their own
local AI IDE accounts and understand usage patterns such as model calls, token
consumption, quota status, and estimated cost from a transparent desktop
dashboard.

The project focuses on practical developer workflow. Many developers work across
personal, work, test, or client environments, and they need a clearer way to see
which local account is active and how AI IDE usage is evolving. Lingxiao AI
Manager keeps this workflow local: saved account sessions remain on the user's
machine, raw sessions are not returned to the frontend account list, and the
project does not depend on a maintainer-owned backend by default.

I am applying for six months of GPT Pro support because it would help me improve
the project as a reliable open-source tool. GPT Pro would accelerate Rust/Tauri
engineering, frontend usability, privacy review, log redaction, documentation,
testing, and issue triage. With that support, I plan to improve cross-platform
reliability, account-store safety, local-only reporting, automated tests, and
the clarity of the open-source security boundary.

The value of the project is not unauthorized account access or limit bypassing.
Its value is developer productivity, local account organization, AI IDE usage
visibility, privacy-aware implementation, and open-source transparency. GPT Pro
support would help me turn it into a more stable and trustworthy tool for
developers who want to manage their AI-assisted workflow responsibly.
